# 云端多人版 · 部署手册

> 目标：一台服务器，同学们各自打开网页 → 填自己账号 → 勾课 → 开刷。互不影响，关网页不影响后台。

---

## 一、买服务器（10 分钟）

### 配置选择

| 人数 | 配置 | 价格参考 |
|---|---|---|
| 1~5 人 | 1核1G | 约 60~100 元/年（新用户） |
| 5~20 人 | **1核2G**（推荐） | 约 100~300 元/年 |
| 20~50 人 | 2核4G | 约 400~700 元/年 |

**推荐：阿里云 或 腾讯云 · 轻量应用服务器 · 2核2G · Ubuntu 22.04**

轻量应用服务器比 ECS/CVM 便宜很多，而且自带防火墙面板，够用。

### 三个必须注意的点

1. **地域选离你近的**（华东1/华北2/华南1）。别选香港/海外——访问超星慢，还容易被判异地登录。
2. **带宽买「按流量」不要买「固定带宽 100Mbps 不限峰值」**，否则被刷流量会爆账单。5Mbps 峰值足够。
3. **镜像选 Ubuntu 22.04**。别选 CentOS 7（已停止维护，Node 20 装不上）和 Windows。

买的时候会设一个 **root 密码**，记下来。

### 开放端口

买完进控制台 → 服务器详情 → **防火墙 / 安全组**：

- 加了域名：放行 **80、443**
- 只用 IP：放行 **8080**

## 二、上传并部署（一条命令）

### 方式 A：我有 SSH 工具（推荐）

1. 把项目文件夹打包上传（Windows 上用 `scp`，或用 WinSCP / FinalShell 拖进去）：

```powershell
# 在你电脑的项目目录里执行
scp -r . root@你的服务器IP:/root/chaoxing
```

2. SSH 登录服务器执行：

```bash
ssh root@你的服务器IP
cd /root/chaoxing
bash deploy/deploy.sh
```

### 方式 B：带域名 + 自动 HTTPS

```bash
bash deploy/deploy.sh --domain cx.example.com --email 你的邮箱@qq.com
```

域名要先解析到服务器 IP（A 记录），解析生效后再跑。

### 方式 C：Docker（喜欢容器的话）

```bash
docker compose -f deploy/docker-compose.yml up -d --build
```

> Docker 部署**必须**在 compose 里加 `ENC_KEY` 环境变量，否则容器重建后保存的密码解不开。用 `deploy.sh` 会自动生成，最省事。

## 三、部署完你会看到

```
================ 部署完成 ================
  访问地址: http://1.2.3.4:8080
  管理员密钥: abc123def456
  查看用户:   http://1.2.3.4:8080/api/admin/users?pwd=abc123def456

  常用命令:
    systemctl status chaoxing      # 看状态
    systemctl restart chaoxing     # 重启
    tail -f /opt/chaoxing/logs/out.log  # 看日志
```

浏览器打开 `http://1.2.3.4:8080` 就是这个页面：

- 手机号/学号 + 密码 → 登录
- 自动列出你的课程 → 勾要刷的
- 点「开始」→ 后台跑，**关网页不影响**
- 再打开网页能看进度和日志

同学们各自登录自己的账号，互相看不到对方数据。

## 五、日常运维

| 要做的事 | 命令 |
|---|---|
| 看服务状态 | `systemctl status chaoxing` |
| 重启 | `systemctl restart chaoxing` |
| 看实时日志 | `tail -f /opt/chaoxing/logs/out.log` |
| 看谁在刷 | `http://IP:8080/api/admin/users?pwd=密钥` |
| 改管理员密码 | 编辑 `/opt/chaoxing/.env` 里 `ADMIN_PASSWORD=`，然后 `systemctl restart chaoxing` |
| 改同时刷课上限 | 同上改 `MAX_RUNNING=` |
| 备份用户数据 | 自动每天 4 点备份到 `/opt/chaoxing/backup/`，保留 7 份 |
| 升级代码 | 重新覆盖文件 → `cd /opt/chaoxing && npm install --omit=dev` → `systemctl restart chaoxing` |

**改了 `.env` 一定要 `systemctl restart chaoxing` 才生效。**

## 六、出问题怎么查

### 网页打不开

```bash
systemctl status chaoxing        # 服务活着吗
curl -I http://127.0.0.1:8080    # 本机能通吗
```

- 本机能通、外面打不开 → **安全组/防火墙没放行端口**（最常见）
- 服务起不来 → `tail -50 /opt/chaoxing/logs/err.log`

### 登录失败

- 「账号或密码错误」→ 密码确实错了，或超星要验证码。**不要在服务器上反复试密码**，超星会锁账号 87 分钟。
- 「需要验证码」→ 让同学先在手机超星 APP 上登录一次，或者等一会儿再试。

### 进度不涨

- 打开日志看有没有 `antispider` / `异常访问`
- 有就是 **IP 被风控**了，不是账号被封。处理：停掉所有任务，等 6~24 小时，降低 `MAX_RUNNING`（改成 5）和每人的 `dailyHours`（改成 2），错开启动时间。
- 详情看 `风控说明.txt`

### 服务器卡死 / 内存爆

```bash
free -h
systemctl status chaoxing
```

2G 内存最多撑 20 人同时刷。人多就 `MAX_RUNNING=10` 排队，或者加机器。

## 七、安全提醒（重要）

1. **`users.json` 里有大家的账号和加密密码**，别外传、别提交到 git。
2. **管理密钥不要发给同学**，只自己留着。
3. `ADMIN_PASSWORD` 别用 123456 这种，脚本会随机生成，直接用它给的。
4. 服务器上不要装宝塔之类带默认口令的面板。
5. 定期 `apt-get update && apt-get upgrade -y` 打补丁。

## 八、想更稳：多发几台小机器

一台机器一个 IP。**同一台机器放的账号越多，被风控连坐的概率越大。**

- 每台 1核2G 放 10~15 人，买 2~3 台 → 就算一台被风控，只影响那一台的人
- 别在同一地域买多台（公网 IP 常在同一 C 段，风控可能按网段封）
- 详见 `IP方案.md`
