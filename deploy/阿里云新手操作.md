# 阿里云新手操作：从"买了但不会用"到"程序跑起来"

> 目标：拿到 **公网 IP** 和 **root 密码**，放开 **8080 端口**。
> 做完这三件事，剩下的发给我，我远程装好。

---

## 第 0 步：登录控制台

浏览器打开 https://www.aliyun.com → 右上角「登录」→ 用买服务器那个账号登。

登录后点右上角 **「控制台」**。

---

## 第 1 步：先看清你买的是哪种

阿里云给个人卖服务器有两个产品，名字很像但控制台不一样：

| 产品 | 你可能看到的名字 | 价格特征 |
|---|---|---|
| **轻量应用服务器** | 轻量应用服务器 / Simple Application Server / SWAS | 便宜，几十到一百多一年，通常带"2核2G"套餐 |
| **云服务器 ECS** | 云服务器 ECS / 实例 | 稍贵，配置可自选 |

**怎么确认**：控制台首页往下拉，找「我的资源」或「最近使用的资源」，看有没有「轻量应用服务器」或「云服务器」。

不确定也没关系，下面两节都对一遍，哪个能看到服务器就走哪个。

---

## 第 2 步（A）：如果你买的是「轻量应用服务器」

1. 直接打开 👉 https://swas.console.aliyun.com
2. **左上角选地域**。不确定买在哪个地域，就在下拉里把「华东1（杭州）」「华北2（北京）」「华南1（深圳）」挨个点一遍，哪个能看到服务器就是哪个。
3. 看到服务器卡片了。**记下卡片上的「公网IP」**（形如 `47.98.xx.xx`）—— 这就是我要的 IP。
4. 点进这台服务器，进入详情页，找到 **「重置密码」**（在"服务器信息"区域，或者右上角更多操作里）。
   - 用户名固定是 `root`
   - 密码：**8~30 位，必须同时有大写字母、小写字母、数字**，例如 `Cx2026flush`
   - 设完点确定。**记下这个密码**。
5. 详情页切到 **「防火墙」** 标签（有的版本叫「安全」）→ 点「添加规则」：
   - 应用类型：**自定义**
   - 端口范围：`8080`
   - 授权对象/来源：`0.0.0.0/0`
   - 点确定
6. 顺便看一眼列表里 **22 端口** 在不在。不在的话同样加一条 `22`，不然我连不上去。

✅ 到这里 A 路线就完了，跳到第 3 步。

---

## 第 2 步（B）：如果你买的是「云服务器 ECS」

1. 打开 👉 https://ecs.console.aliyun.com
2. 左侧菜单点 **「实例」**。**左上角地域**同样挨个试，找到有实例的那个。
3. 实例列表里，**记下「公网IP地址」**那一列的值。
4. **设 root 密码**：找到你的实例，最右边 **「更多」→「密码/密钥」→「重置实例密码」**
   - 密码规则同上：8~30 位，大小写字母 + 数字，例如 `Cx2026flush`
   - ⚠ **设完必须重启实例才生效**：右侧「更多」→「实例状态」→「重启」
5. **开端口**：左侧菜单点 **「网络与安全」→「安全组」** → 找到你这台实例用的安全组 → 点 **「配置规则」**
   - 点「手动添加」/「入方向」→「添加安全组规则」
   - 端口范围：`8080/8080`
   - 授权对象：`0.0.0.0/0`
   - 点保存
6. 同样确认 `22/22` 也放行了（新建实例一般默认开 22）。

✅ 到这里 B 路线就完了。

---

## 第 3 步：确认系统是 Ubuntu

我的部署脚本是给 Ubuntu 写的。新买的大概率是，但要确认一下。

**在哪看**：服务器详情页上会写「镜像」或「操作系统」，类似 `Ubuntu 22.04 64位`。

- 显示 **Ubuntu 20.04 / 22.04 / 24.04** → 完美，不用动
- 显示 **CentOS / Alibaba Cloud Linux / Debian** → 大概率也能跑，但我要先看一眼
- 显示 **Windows Server** → 必须换系统

**换系统**（新服务器没数据，放心换）：
- 轻量：详情页 →「重置系统」→ 选 `Ubuntu 22.04` → 确定
- ECS：「更多」→「云盘和镜像」→「更换操作系统」→ 选 Ubuntu 22.04

> 换完系统 root 密码可能会重置，需要重新设一次（回到第 2 步的第 4 小步）。

---

## 第 4 步：把信息发我

发这两样就行：

```

root 密码：Cx2026flush
```

我这边执行一条命令就装完了，大概 2~4 分钟，然后把访问地址和管理员密钥给你。

装完我会告诉你：

```
访问地址: http://47.98.xx.xx:8080
管理员密钥: xxxxxxxxxxxx
```

## 附：常见疑问

**Q：会不会把我账号密码泄露？**
服务器上的密码是用 AES 加密存的，密钥在服务器本地 `.env` 里。但说实话——**你给了我 root 密码，技术上我什么都能看**。所以：装完你自己改一次 root 密码，我就进不去了。或者你想更安全，用「密钥对」登录，只给我公钥。

**Q：为什么是 8080 端口，不用 80？**
80 要给域名 + HTTPS 用。先用 8080 跑起来验证，想上域名再说（我一条命令能配好）。

**Q：服务器要一直开着吗？**
要。刷课任务在后台跑，关机就停。按量付费的记得设「自动释放」以免忘关机扣钱；包年的无所谓。

**Q：买的地域选错了有影响吗？**
选香港/海外：访问超星慢，容易被判异地登录，建议国内。如果已经买了香港，也能用，就是慢点。

**Q：一个人用还是多个人用？**
这台服务器上可以开一个网页，多个同学各自登录自己的账号，互相看不到数据。2核2G 建议**不超过 15 人**同时刷。

**Q：会不会因为人太多被封 IP？**
会，这是最大风险。详见 `风控说明.txt` 和 `IP方案.md`。核心建议：每人每天 2~3 小时、错开时间、别同时开好几路。
